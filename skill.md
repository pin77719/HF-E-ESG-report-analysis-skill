# HF/E ESG Report Analysis Skill

## 1. Skill Purpose

This skill is designed to support the analysis of Human Factors/Ergonomics (HF/E) related disclosures in corporate ESG sustainability reports.

The purpose of this skill is to identify whether a sustainability report passage contains HF/E-related content, classify the content according to ergonomics domains, connect it with ESG dimensions, and evaluate the depth of disclosure.

## 2. Input

The input may include:

- A paragraph from a corporate sustainability report
- ESG report text
- GRI-related disclosure content
- Occupational safety and health descriptions
- Employee training, workplace improvement, process improvement, or environmental performance descriptions

## 3. Analysis Workflow

1. Read the input text.
2. Identify whether the text contains HF/E-related content.
3. Classify the HF/E content into one of the following domains:
   - Physical ergonomics
   - Cognitive ergonomics
   - Organizational ergonomics
4. Determine the related ESG dimension:
   - Social dimension
   - Environmental dimension
   - Social-Environmental linkage
5. Evaluate the disclosure depth using a 0–3 scoring scale.
6. Provide the analysis result and reasoning.

## 4. Disclosure Depth Scoring

| Score | Description |
|---|---|
| 0 | No HF/E-related disclosure |
| 1 | General or slogan-like statement only |
| 2 | Specific policy, practice, system, or measure is described |
| 3 | Quantitative result, performance indicator, case, or tracking mechanism is provided |

## 5. Output Format

The output should include:

- Original text
- Whether HF/E content is identified
- HF/E domain
- ESG dimension
- Disclosure depth score
- Reasoning
- Suggested improvement
