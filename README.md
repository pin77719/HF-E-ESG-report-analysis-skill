# HF/E ESG Report Analysis Skill

## 專案簡介

本專案為期末報告作業成果，主題為 **HF/E ESG Report Analysis Skill**。

此專案目的在建立一套用於分析企業永續報告書中人因工程（Human Factors/Ergonomics, HF/E）相關揭露內容的個人工作流程 Skill，並呈現如何運用 AI 工具協助進行永續報告書內容分析。

## 專案目的

本 Skill 可協助使用者針對企業永續報告書中的文字段落進行初步判讀，包含：

1. 判斷段落是否涉及人因工程相關內容。
2. 將內容分類為物理人因、認知人因或組織人因。
3. 判斷該內容對應 ESG 中的社會構面、環境構面或社會－環境連結。
4. 依據揭露深度給予 0 至 3 分。
5. 輸出結構化分析結果與判斷理由。

## Skill 使用情境

此 Skill 適用於下列情境：

- 分析企業永續報告書段落
- 辨識職業安全衛生、教育訓練、工作環境改善等人因工程相關內容
- 判斷人因工程內容與 ESG 社會構面或環境構面的關係
- 建立永續報告書內容分析的初步編碼與評分依據

## 揭露深度評分標準

| 分數 | 說明 |
|---|---|
| 0 分 | 未揭露與人因工程相關內容 |
| 1 分 | 僅原則性、口號式或概念性提及 |
| 2 分 | 具體說明制度、措施、作法或改善活動 |
| 3 分 | 提供量化成果、績效指標、案例、追蹤機制或改善成效 |

## 預期成果

透過本 Skill，使用者可以將永續報告書中的文字內容轉換為結構化分析結果，作為後續內容分析、編碼架構設計與 ESG 揭露研究的參考。

## 後續作品規劃

後續將建立一個簡單的展示工具，讓使用者輸入永續報告書段落後，產生以下分析結果：

- 是否涉及人因工程
- 人因工程分類
- ESG 對應構面
- 揭露深度分數
- 判斷理由
- 改善建議
